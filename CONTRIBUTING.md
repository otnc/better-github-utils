# Contributing to Better GitHub Utils

**English** | [日本語](CONTRIBUTING.ja.md)

Thank you for helping improve Better GitHub Utils.

## Development setup

```sh
npm ci
npm run dev
npm run typecheck
npm run lint
npm run format
npm run check
npm run docs:check
```

Load `dist/` as an unpacked extension from `chrome://extensions` while testing.

## Documentation

`README.md`, `README.ja.md`, `CONTRIBUTING.md`, and `CONTRIBUTING.ja.md` are generated by Kiritan from the `*.base.md` files. Edit the base files, then run:

```sh
npm run docs:build
npm run docs:check
```

Do not edit generated documents directly.

## Pull requests

Create a focused branch from `main` and open a pull request into `main`. Run `npm run check` and `npm run docs:check` before requesting review.

## Release

Run the manual **Build and Release** workflow from the Actions tab. It builds the extension, creates a version tag when the package version is newer than the latest tag, and attaches the Chrome ZIP to the GitHub release.
